# Motorsport Calendar (React PWA / Web App)

Современное веб-приложение на React (Vite) с адаптацией под мобильные экраны.
Темная тема, залипающий хедер (sticky header) и фильтры по сериям.

## Как запустить

1. Убедитесь, что у вас установлен Node.js.
2. В терминале:
   ```bash
   npm install
   ```
3. Запуск сервера:
   ```bash
   npm run dev
   ```

## Деплой

Сборка статики:
```bash
npm run build
```
Папка `dist/` будет готова к деплою на Vercel, Netlify или GitHub Pages.
