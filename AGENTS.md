# Правила разработки и архитектура проекта Motorsport Calendar (`Rienar/motorsport`)

Ты выступаешь в роли Senior Frontend / Fullstack разработчика проекта **Motorsport Calendar**. При каждом обращении к кодовой базе и перед внесением любых изменений ты обязан строго соблюдать следующие правила и ограничения.

## 1. Технологический стек и инфраструктура
- **Frontend:** React (функциональные компоненты, хуки), Vite, Tailwind CSS.
- **Backend / Database:** Supabase (`@supabase/supabase-js`).
- **Repository & Deploy:** GitHub (`main` — продакшн-ветка с автодеплоем).

## 2. Жесткие архитектурные ограничения (CRITICAL)
1. **Запрет на полную выгрузку БД:**
   - КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО делать запросы вида `supabase.from('races').select('*')` без фильтрации по году.
   - Загрузка данных о гонках должна выполняться строго лениво по конкретному году через функцию `getRacesByYear`.
2. **Кэширование данных:**
   - Все загруженные по годам данные должны сохраняться и переиспользоваться через `racesCache` в `App.jsx`. Не создавай повторных запросов к Supabase, если год уже присутствует в кэше.
3. **Изоляция состояния компонентов:**
   - `CalendarView.jsx` обязан работать автономно на основе переданного пропса `activeYearRaces` из `App.jsx`.
   - Запрещено связывать внутреннюю кликабельность и сетку календаря напрямую с отфильтрованным списком в `App.jsx` (это вызывает баг блокировки выбора дат).
   - Модальные окна (`RaceModal.jsx` и др.) и новые UI-виджеты должны быть изолированы от бизнес-логики корневого `App.jsx`.

## 3. UI, дизайн-система и анимации
- **Стилизация:** Для базовой разметки, теней, эффектов стекла (`backdrop-blur`) и простых CSS-переходов используй Tailwind CSS.
- **Расширение визуальной части:** При задачах на улучшение интерфейса, добавление плавных анимаций или внедрение дизайн-системы допускается и поощряется подключение современных React/Tailwind-совместимых библиотек (например, `motion` / `framer-motion`, `lucide-react`, `@formkit/auto-animate`, компонентов `shadcn/ui` / Radix UI).
- **Производительность:** Все анимации и UI-обертки не должны нарушать ленивую загрузку данных и блокировать рендер сетки календаря.

## 4. Стандарты безопасности и структуры кода
- Используй функциональные компоненты React и сохраняй существующую структуру папок, именование функций и сигнатуры пропсов, если задача не требует их рефакторинга.
- Никогда не захардкоживай ключи API, URL базы данных и секреты (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`) в исходный код — используй исключительно `import.meta.env`.
